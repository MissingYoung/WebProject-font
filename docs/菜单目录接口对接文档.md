# 菜单/目录接口对接文档

## 一、接口概述

**功能**：根据当前登录用户的角色权限，返回该用户可访问的菜单树形结构。

**特点**：
- 自动根据用户角色过滤菜单
- 支持树形层级结构（目录 + 菜单）
- 自动按 `sort` 字段排序
- 只返回状态为正常的菜单项

## 三、字段说明

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `id` | Long | 菜单ID | 1 |
| `parentId` | Long | 父菜单ID，顶级菜单为 `null` | null 或 1 |
| `name` | String | 菜单显示名称 | "系统管理" |
| `key` | String | 权限标识（唯一） | "system" 或 "system:user" |
| `type` | String | 菜单类型：<br>- `DIRECTORY`：目录（不可点击）<br>- `MENU`：菜单项（可点击跳转） | "DIRECTORY" 或 "MENU" |
| `menuUrl` | String | 前端路由路径，目录类型时为 `null` | "/system/user" |
| `icon` | String | 图标名称（根据你们的图标库） | "user", "setting" |
| `sort` | Integer | 排序序号（升序），数字越小越靠前 | 1, 2, 3 |
| `children` | Array | 子菜单列表，空数组表示无子菜单 | [] |

## 四、前端使用指南

### 1. 调用时机
```javascript
// 建议在用户登录成功后立即调用
async function initMenu() {
  const response = await fetch('/menu/current', {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${localStorage.getItem('token')}`
    }
  });

  const result = await response.json();
  if (result.code === 200) {
    // 存储菜单数据用于渲染侧边栏
    localStorage.setItem('menuTree', JSON.stringify(result.data));
    renderSideMenu(result.data);
  }
}
```

### 2. 渲染菜单树
```javascript
// 递归渲染示例（React）
function MenuTree({ data }) {
  return (
    <ul>
      {data.map(item => (
        <li key={item.id}>
          {item.type === 'DIRECTORY' ? (
            // 目录：不可点击，显示图标和名称
            <div className="menu-directory">
              <Icon type={item.icon} />
              <span>{item.name}</span>
            </div>
          ) : (
            // 菜单项：可点击跳转
            <Link to={item.menuUrl}>
              <Icon type={item.icon} />
              <span>{item.name}</span>
            </Link>
          )}

          {/* 递归渲染子菜单 */}
          {item.children.length > 0 && (
            <MenuTree data={item.children} />
          )}
        </li>
      ))}
    </ul>
  );
}
```

### 3. 路由配置注意事项
- 前端路由路径应与后端返回的 `menuUrl` 保持一致
- `DIRECTORY` 类型的 `menuUrl` 为 `null`，不需要注册路由
- 只有 `MENU` 类型才需要配置实际的路由页面

## 五、预配置菜单项数据格式

**用途**：管理员在后台配置菜单/权限时，前端需要向后端提交以下数据结构。

### 1. 菜单配置数据格式

```json
{
  "parentId": null,
  "name": "系统管理",
  "key": "system",
  "type": "DIRECTORY",
  "menuUrl": null,
  "icon": "setting",
  "sort": 1,
  "status": "NORMAL"
}
```

### 2. 字段说明（供配置使用）

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `parentId` | Long | 否 | 父菜单ID，顶级菜单填 `null` | null 或 1 |
| `name` | String | **是** | 菜单显示名称 | "用户管理" |
| `key` | String | **是** | 权限标识（唯一），建议格式：`父级:子级` | "system:user" |
| `type` | String | **是** | 菜单类型：`DIRECTORY` 或 `MENU` | "MENU" |
| `menuUrl` | String | 条件必填 | 前端路由路径，`MENU` 类型必填，`DIRECTORY` 填 `null` | "/system/user" |
| `icon` | String | 否 | 图标名称 | "user" |
| `sort` | Integer | 否 | 排序序号，默认按ID排序 | 1 |
| `status` | String | 否 | 状态：`NORMAL`（正常）或 `DISABLED`（禁用），默认 `NORMAL` | "NORMAL" |

### 3. 配置规则

**目录（DIRECTORY）配置**：
```json
{
  "parentId": null,
  "name": "系统管理",
  "key": "system",
  "type": "DIRECTORY",
  "menuUrl": null,        // 目录不需要URL
  "icon": "setting",
  "sort": 1
}
```

**菜单项（MENU）配置**：
```json
{
  "parentId": 1,           // 父目录ID
  "name": "用户管理",
  "key": "system:user",
  "type": "MENU",
  "menuUrl": "/system/user",  // 必须提供URL
  "icon": "user",
  "sort": 1
}
```

### 4. 命名建议

**权限标识（key）命名规范**：
- 顶级目录：`system`, `course`, `student`
- 二级菜单：`system:user`, `course:list`
- 操作权限：`system:user:create`, `system:user:edit`

**前端路由（menuUrl）命名规范**：
- 保持与 `key` 一致：`/system/user`
- 支持嵌套路由：`/course/list`, `/course/detail`

## 七、常见问题

### Q1: 菜单树如何排序？
**A**: 后端自动按 `sort` 字段升序排序，数字越小越靠前。同级菜单建议设置为 1, 2, 3...

### Q2: 如何区分目录和菜单？
**A**: 通过 `type` 字段：
- `DIRECTORY`：目录，不可点击，用于分组
- `MENU`：菜单项，可点击跳转到具体页面

### Q3: 用户看不到某些菜单怎么办？
**A**: 这是权限控制的结果，需要管理员在后台为该用户的角色分配相应的菜单权限。

### Q4: 如何支持多级菜单？
**A**: 通过 `parentId` 实现无限层级：
- 一级菜单：`parentId = null`
- 二级菜单：`parentId = 一级菜单ID`
- 三级菜单：`parentId = 二级菜单ID`
- 依此类推

### Q5: 图标字段支持什么格式？
**A**: 建议使用图标库的图标名称（如 Ant Design Icons: `user`, `setting`, `book`），前端根据名称渲染对应图标。

### Q6: 接口返回的菜单会自动更新吗？
**A**: 不会。菜单数据在用户登录时获取并缓存。如果修改了用户权限或菜单配置，需要用户重新登录或刷新菜单接口。

## 八、技术实现说明

### 后端实现

**Controller**: `MenuController.java`
- 路径：`src/main/java/work/foofish/webapi/controller/MenuController.java`
- 接口：`GET /menu/current`
- 权限：需要登录（`@SaCheckLogin`）

**Service**: `MenuService.java`
- 路径：`src/main/java/work/foofish/webapi/service/MenuService.java`
- 功能：
  - 获取当前登录用户ID
  - 查询用户的菜单权限列表
  - 构建树形结构
  - 按 sort 字段排序

**Mapper**: `PermissionMapper.java`
- 路径：`src/main/java/work/foofish/webapi/mapper/PermissionMapper.java`
- 方法：`getMenuPermissionsByUserId(Long userId)`
- SQL查询：
  ```sql
  SELECT p.id, p.parent_id, p.name, p.`key`, p.type,
         p.menu_url, p.icon, p.sort, p.status
  FROM permission p
  JOIN role_permission_rel rpr ON p.id = rpr.permission_id
  JOIN `user` u ON rpr.role_id = u.role_id
  WHERE u.id = #{userId}
    AND p.is_deleted = 0
    AND p.type IN (0, 1)
    AND p.status = 1
  ORDER BY p.sort ASC, p.id ASC
  ```

**VO**: `MenuVO.java`
- 路径：`src/main/java/work/foofish/webapi/model/vo/MenuVO.java`
- 字段：id, parentId, name, key, type, menuUrl, icon, sort, children

## 九、总结

✅ **完整的路由和菜单配置清单**（JSON 或 Excel）
