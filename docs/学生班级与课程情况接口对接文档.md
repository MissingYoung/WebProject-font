# 1. 说明

该接口用于“学生查看自己的班级与课程情况”页面的数据获取：包含学生个人基础信息、学院/专业/行政班信息，以及指定学期（默认当前学期）的已选课程分页列表。

统一响应包装为 `Result<T>`：

```json
{
  "code": 200,
  "message": "成功",
  "data": {},
  "bizCode": null
}
```

- `code=200` 表示成功
- `code!=200` 表示失败，`message` 为错误说明，`bizCode`（若有）为稳定的业务错误标识

# 2. 认证方式

使用 Sa-Token。

- Header：`satoken: <token>`
- token 来源：登录接口 `POST /auth/login` 的返回值 `data.token`

未登录会返回 `code=401`，无权限会返回 `code=403`。

# 3. 接口列表

## 3.1 获取“班级与课程情况”总览（学生）

**接口**

- Method：`GET`
- Path：`/student/me/overview`
- 权限：`student` 角色（`@SaCheckPermission(orRole="student")`）

**Query 参数**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `semesterId` | number | 否 | 学期 ID；不传则默认当前学期；若系统未设置当前学期，则不按学期过滤 |
| `pageNum` | number | 否 | 课程分页页码，默认 `1` |
| `pageSize` | number | 否 | 课程分页大小，默认 `20` |
| `includeSchedules` | boolean | 否 | 是否在课程列表中附带排课明细（`CourseEnrollmentVO.schedules`），默认 `false` |

**成功响应**

`Result<StudentClassCourseOverviewVO>`

### 3.1.1 data 字段说明（StudentClassCourseOverviewVO）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `user` | object | 当前用户基础信息 |
| `student` | object | 学生学籍信息（部分字段） |
| `department` | `DepartmentVO \| null` | 学院信息（若未设置则为 null） |
| `major` | `MajorVO \| null` | 专业信息（若未设置则为 null） |
| `administrativeClass` | `AdministrativeClassVO \| null` | 行政班信息（若未分班则为 null） |
| `semester` | `SemesterVO \| null` | 当前（或指定）学期信息（若无则为 null） |
| `enrollmentSummary` | object | 已选课程汇总 |
| `enrollments` | `PageResult<CourseEnrollmentVO>` | 已选课程分页（仅 `SELECTED` 状态） |

### 3.1.2 user（StudentClassCourseOverviewVO.user）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 用户 ID |
| `username` | string | 用户名 |
| `realName` | string | 姓名 |
| `sduId` | string | 学工号/学号 |
| `phone` | string \| null | 手机号 |
| `email` | string \| null | 邮箱 |
| `avatarUrl` | string \| null | 头像 |

### 3.1.3 student（StudentClassCourseOverviewVO.student）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 学生 ID（student 表主键） |
| `entryYear` | number \| null | 入学年份 |
| `gradeLevel` | number \| null | 年级 |

### 3.1.4 enrollmentSummary（StudentClassCourseOverviewVO.enrollmentSummary）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `courseCount` | number | 已选课程总数（对应 `enrollments.total`） |
| `totalCredits` | string/number | 已选课程总学分；后端为 `BigDecimal`，JSON 中可能表现为数字或字符串（依赖序列化配置） |

### 3.1.5 enrollments（PageResult<CourseEnrollmentVO>）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `records` | array | `CourseEnrollmentVO[]` |
| `total` | number | 总记录数 |
| `pageNum` | number | 当前页 |
| `pageSize` | number | 每页数量 |
| `pages` | number | 总页数 |

### 3.1.6 CourseEnrollmentVO（重要字段）

该结构为系统已有 VO，本接口会返回其中常用字段（联表查询得到）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 选课记录 ID |
| `teachingClassId` | number | 教学班 ID |
| `teachingClassCode` | string \| null | 教学班编号 |
| `teachingClassName` | string \| null | 教学班名称 |
| `location` | string \| null | 上课地点（教学班字段） |
| `courseId` | number \| null | 课程 ID |
| `courseCode` | string \| null | 课程编号 |
| `courseName` | string \| null | 课程名称 |
| `credit` | number \| null | 学分 |
| `courseType` | string \| null | 课程类型（枚举） |
| `semesterId` | number \| null | 学期 ID |
| `semesterName` | string \| null | 学期名称 |
| `teacherId` | number \| null | 教师 ID |
| `teacherName` | string \| null | 教师姓名 |
| `teacherEmployeeId` | string \| null | 教师工号 |
| `schedules` | array \| null | 仅当 `includeSchedules=true` 时返回（否则通常为 null） |

`schedules` 为 `TeachingClassScheduleVO[]`，常用字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `weekDay` | number | 周几（1-7，1=周一） |
| `startWeek` | number | 起始周 |
| `endWeek` | number | 结束周 |
| `startSection` | number | 开始节次 |
| `endSection` | number | 结束节次 |
| `classroom` | string \| null | 教室 |
| `remark` | string \| null | 备注 |

**请求示例**

```bash
curl -s 'http://localhost:8080/student/me/overview?pageNum=1&pageSize=20&includeSchedules=true' \
  -H 'satoken: <token>'
```

# 4. 错误码说明（常见）

| code | 含义 | 说明 |
| --- | --- | --- |
| 200 | 成功 | |
| 400 | 参数/业务校验失败 | 例如“学生信息不存在” |
| 401 | 未登录/登录过期 | Sa-Token 拦截 |
| 403 | 无权限 | 非 student 角色 |
| 500 | 服务器错误 | 未捕获异常 |
