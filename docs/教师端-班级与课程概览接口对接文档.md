# 教师端：班级与课程概览接口对接文档

## 1. 接口概述

用于教师端单独设计的“我的班级与课程情况”页面，一次性返回：
- 教师信息（userId/teacherId/姓名）
- 当前学期信息（可选）
- 教学班列表（可按学期过滤）
- 课程汇总（由教学班聚合）
- 我担任班主任/辅导员的行政班列表

后端接口：`GET /teacher/me/dashboard`

> 说明：如果你们前端统一加了前缀（例如 `/api`），则实际请求路径以 `baseURL` 为准（如 `/api/teacher/me/dashboard`）。

---

## 2. 鉴权

- 需要登录（Sa-Token）。
- 仅 `teacher` 角色可访问。

请求头示例：

```http
Authorization: Bearer {token}
```

---

## 3. 获取教师概览数据

### 3.1 请求

**接口地址**：`GET /teacher/me/dashboard`

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `semesterId` | Long | 否 | 学期 ID；为空时优先使用“当前学期”；若系统未设置当前学期则返回跨学期汇总（`semester` 字段为 `null`） |

### 3.3 字段说明

#### 3.3.1 data（TeacherDashboardVO）

| 字段 | 类型 | 说明 |
|---|---|---|
| `userId` | Long | 当前登录用户 ID |
| `teacherId` | Long | 教师表主键 ID |
| `teacherName` | String | 教师姓名（User.realName） |
| `semester` | SemesterVO \| null | 当前/指定学期信息；跨学期汇总时为 `null` |
| `stats` | Stats | 统计信息 |
| `teachingClasses` | TeachingClassVO[] | 教学班列表（可能为空数组） |
| `courses` | CourseSummary[] | 课程汇总（由教学班按 `courseId` 聚合） |
| `administrativeClasses` | AdministrativeClassVO[] | 行政班列表（我担任班主任/辅导员） |

#### 3.3.2 stats（TeacherDashboardVO.Stats）

| 字段 | 类型 | 说明 |
|---|---|---|
| `teachingClassCount` | Integer | 教学班数量 |
| `courseCount` | Integer | 课程数量（去重后） |
| `administrativeClassCount` | Integer | 行政班数量 |
| `totalEnrolledCount` | Integer | 教学班已选人数合计（所有 `enrolledCount` 累加） |

#### 3.3.3 courses（TeacherDashboardVO.CourseSummary）

| 字段 | 类型 | 说明 |
|---|---|---|
| `courseId` | Long | 课程 ID |
| `courseCode` | String | 课程编号 |
| `courseName` | String | 课程名称 |
| `credit` | Double | 学分 |
| `teachingClassCount` | Integer | 该课程对应的教学班数量 |
| `enrolledCount` | Integer | 该课程下教学班已选人数合计 |

> 备注：`teachingClasses` 的字段与 `TeachingClassVO` 一致；`administrativeClasses` 的字段与 `AdministrativeClassVO` 一致。

## 4. 错误码约定（Result.code）

| code | 场景 | message 示例 |
|---:|---|---|
| 200 | 成功 | 成功 |
| 401 | 未登录或登录过期 | 未登录或登录已过期 |
| 403 | 非教师角色访问 | 权限不足 |
| 400 | 参数/数据不合法 | 学期不存在 / 教师信息不存在 |
| 500 | 服务器内部错误 | 服务器内部错误 |
