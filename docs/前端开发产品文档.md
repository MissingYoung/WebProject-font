## 1. 项目概述

### 1.1 系统简介

教务管理系统是一个全栈的教育管理平台，提供学生选课、教师管理、课程管理、院系管理等核心教务功能。系统采用前后端分离架构，后端提供RESTful API接口，支持多角色权限管理。

### 1.2 核心特性

- ✅ **用户管理**：支持管理员、教师、学生三种角色，细粒度权限控制
- ✅ **组织架构**：完整的院系-专业-行政班层级管理
- ✅ **课程体系**：课程-课程开设-教学班-选课的完整教学流程
- ✅ **选课系统**：学生在线选课、退课，容量控制，状态管理
- ✅ **文件上传**：基于Cloudflare R2的图片上传功能
- ✅ **邮件服务**：邮箱验证、密码重置、邮件通知
- ✅ **数据安全**：BCrypt密码加密、Sa-Token身份认证、软删除机制

## 4. 认证与授权

### 4.1 认证流程

```
┌──────────┐      登录请求       ┌──────────┐
│          │ ─────────────────> │          │
│  前端    │   (sduId+password)  │  后端    │
│          │ <───────────────── │          │
└──────────┘   返回Token+用户信息 └──────────┘
     │
     │ 存储Token到cookie
     │
     ├
     │
     └──> 登出后删除Token
```

### 4.2 Token使用

**Token名称**：`satoken`
**Token位置**：HTTP Header
**Token格式**：UUID字符串
**Token有效期**：30天
**Token存储**：Redis

**请求示例**：

```http
GET /api/user/profile HTTP/1.1
Host: localhost:8081
satoken: a1b2c3d4-e5f6-g7h8-i9j0-k1l2m3n4o5p6
Content-Type: application/json
```

#### 4.3.1 系统角色

| 角色标识  | 角色名称 | 说明                            |

## 5. API接口规范

### 5.1 统一响应格式

所有API接口返回统一的JSON格式：

```json
{
  "code": 200,           // 响应码（200=成功，其他=失败）
  "message": "成功",      // 响应消息
  "data": {}             // 响应数据（可为null、对象、数组）
}
```

#### 响应码说明

| 响应码 | 说明         | 示例                           |
| ------ | ------------ | ------------------------------ |
| 200    | 成功         | 操作成功                       |
| 400    | 请求参数错误 | 参数校验失败、业务规则校验失败 |
| 401    | 未登录       | Token无效或已过期              |
| 403    | 权限不足     | 无对应权限                     |
| 404    | 资源不存在   | 用户不存在、课程不存在         |
| 409    | 冲突         | 用户名已存在、课程编号重复     |
| 500    | 服务器错误   | 系统异常                       |

### 5.2 分页响应格式

分页查询接口的响应数据格式：

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "records": [],        // 数据列表
    "total": 100,         // 总记录数
    "pageNum": 1,         // 当前页码
    "pageSize": 20,       // 每页数量
    "pages": 5            // 总页数
  }
}
```

### 5.3 分页查询参数

所有分页查询接口支持以下通用参数：

| 参数       | 类型    | 必填 | 默认值 | 说明            |
| ---------- | ------- | ---- | ------ | --------------- |
| `pageNum`  | Integer | 否   | 1      | 页码（从1开始） |
| `pageSize` | Integer | 否   | 20     | 每页数量        |

### 5.4 日期时间格式

所有日期时间字段统一使用ISO 8601格式：

- **日期**：`YYYY-MM-DD` (如：`2024-12-29`)
- **时间**：`HH:mm:ss` (如：`14:30:00`)
- **日期时间**：`YYYY-MM-DDTHH:mm:ss+08:00` (如：`2024-12-29T14:30:00+08:00`)
